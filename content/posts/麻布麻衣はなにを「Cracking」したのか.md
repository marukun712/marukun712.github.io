# ハッキングとクラッキング

皆さんは、深夜のデスクでパソコンをカタカタしているイメージに対して、どのような言葉が思い浮かびますか?

おそらく、「ハッキング」という言葉が浮かぶ人も多いでしょう。一方、Public Styleの歌詞で登場している「cracking」(クラッキング)という言葉は、耳馴染みのない方も多いかもしれません。

この、「ハッキング」と「クラッキング」は、本来の意味と世間のイメージがずれている言葉として有名です。

ハッキングと聞くと、システムに対して攻撃して、最近流行りの身代金を要求したり、情報を漏洩させたりするイメージを持っている方が多いと思います。

ですが、本来このイメージに当たる言葉こそが「クラッキング」です。

https://e-words.jp/w/%E3%82%AF%E3%83%A9%E3%83%83%E3%82%AD%E3%83%B3%E3%82%B0.html

ハッキングという言葉は本来、システムの複雑な課題を解決したり、システムの安全性に貢献するような行いをするなど、肯定的な意味で用いられてきました。よく使われる言葉で言うと、ホワイトハッカー(またはホワイトハットハッカー)に近いかもしれません。

https://e-words.jp/w/%E3%83%8F%E3%83%83%E3%82%AD%E3%83%B3%E3%82%B0.html

それに対して、クラッキングは犯罪を目的とした悪意ある攻撃を指す言葉として区別されてきました。

# なぜ「クラッキング」？

ではなぜ、(言葉の本来の意味を考慮するならば)ハッキングという善意とも取れる言葉ではなく、なぜ悪意の行為として定義されたクラッキングという言葉を、あえて歌詞の冒頭で使用したのでしょうか。私はこの部分に以前から引っかかりを感じていました。

私はこのフレーズの始めに、あえて crackingという言葉=悪いイメージの言葉 を使った理由は、麻衣ちゃんの感じている「**後ろめたさ**」を表現するためだと考えています。

ここで、改めてPublic Styleの歌詞全体を眺めてみましょう。

```
本音ばかりじゃダメダメ
ウソにタテマエ言わなきゃ
本当のことを言ったら
この世は私をはじき出して閉じる
```

曲中で何度も繰り返されるこのフレーズは、麻衣ちゃんの本音(プログラミングや数学、TRONのこと話したいという気持ち)を、社会からはじき出されるという不安から、「タテマエ」を使って抑えている、という内容です。

そんな麻衣ちゃんの葛藤は、本人のツイートからも確認することが出来ます。

https://x.com/My_Mai_Eld/status/1937476045122519426
> だから休み時間に女の子同士で「好きな人の話」とか あり得ないから💩 私の憧れはパパが持ってる古い超漢字！！ えーもしかして超漢字知らないの！？ そんなの恋愛とかにうつつを抜かしてる場合じゃなくない？

https://x.com/My_Mai_Eld/status/1937476800260510041
> なんて本当のことを言ったら この世は私をはじき出して閉じるから ずっとウソとタテマエを使い続けてきた 私のストレスフルな対女子ライフ

そんな孤独の中でも、麻衣ちゃんは希望を捨てているわけではありません。

```
離れていたって It's Alright
世界に向けて いつか届く気がするから
ゼロイチきっぱり So Happy
それでもいい？なら天下とりにいくわよ
フルスクラッチ
```

自分のこの気持ちは、いつか誰かに届く、ということを信じながら、日々猫を被っているのです。

歌詞全体の流れを確認したところで、最初のフレーズに戻ります。

```
cracking 真夜中のデスク
光るモニターの向こうがわ 遠いベッド
```

この歌詞からは、麻衣ちゃんが深夜にデスクに向かい、パソカタをしているイメージが浮かびます。

皆さんも、明日を先延ばしにしたくて、ついつい夜ふかしをしてしまった経験が、一度はありませんか?

同様に、麻衣ちゃんにとって深夜のデスクに向かう時間は、孤独を感じたまま猫をかぶる明日を先延ばしにするための、ある種の「逃げ」に感じられていて、crackingという言葉はその**後ろめたさの象徴**だったのかもしれません。
